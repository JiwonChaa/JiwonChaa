## 소개

고등학교에서 물리를 가르치며, 경희대학교 교육대학원에서 물리교육을 공부한다.

다루는 일은 다음과 같다.

- **교육과정 분석:** 석사 논문에서 반도체 웨이퍼 공정과 계측, 검사에 나타난 물리 내용을 2022 개정 고등학교 물리 교육과정과 대응시키고 있다. 분석에는 국가직무능력표준(NCS) 학습모듈에서 뽑은 판정 단위 642개를 쓴다.
- **공개 물리 교재:** [phyedu.net](https://phyedu.net/)을 집필하고 운영하며, 56개 계열에 약 2,600편과 조작형 시뮬레이션 59개를 제공한다. 고등학교 역학부터 대학원 주제까지 다룬다.
- **물리로 가르치는 인공지능:** 학생이 물리 실험에서 이미 다루는 개념으로 기계학습을 도입하는 고등학교 수업이다. 최소제곱법으로 손실함수를, 비탈을 굴러 내려가는 공으로 경사하강을, 열확산과 그 역과정으로 확산 모델을 설명한다.
- **기계학습 실험:** 모델 학습을 측정 문제로 다룬다. 작은 CNN을 156회 학습시켜 일변량 실험, 플래킷–버먼 설계, 완전요인설계를 비교했고, 초파리 커넥톰 전뇌 모델을 GPU에서 돌려 공개된 모델과 스파이크 단위로 대조했다.
- **학생 연구와 로봇 지도:** 질량을 교대로 매단 줄의 진동 밴드갭, FTC(FIRST Tech Challenge) 로봇 코드 워크플로, ROS 2 자율주행 로봇 등 물리와 공학 분야의 학생 과제를 지도한다.
- **학교 업무 도구:** 교내에 LLM 서버를 두고 탐구 주제 검색, 모의고사 진단, 대입 면접 준비에 쓰는 도구를 만든다.
- **커뮤니티:** 네이버 카페 [물리 세계로의 즐거운 항해](https://cafe.naver.com/physvoyage)의 부매니저를 맡고 있다.

<summary><b>실패와 수정</b></summary>

<br>

- **재기동마다 달라지는 속도:** 같은 설정에서 추론 속도가 초당 21토큰과 93토큰을 오갔다. 서버가 기동 순간의 여유 VRAM을 기준으로 캐시 크기를 정했고, 이후 데스크톱 프로그램이 돌아오면 초과분이 시스템 RAM으로 밀려났기 때문이다. GPU 메모리 점유율을 0.92에서 0.87로 낮추어 해결했다.
- **RAG의 허위 답변:** 임베딩 컨테이너에만 재시작 설정이 빠져 있어서, 재부팅 뒤에 이 컨테이너가 꺼진 채로 남았다.
- **검색 결과가 적을 때 지어낸 인용:** 검색 결과가 2건뿐이면 프롬프트가 엄격해도 모델이 인용 형식을 채우려고 출처를 지어냈다. 검색을 확대하자 시험 질의 5개에서 나온 인용 29건이 모두 검색 결과에 실재했다.
- **채점 예시 제거 후의 관대한 채점:** 평가 하네스에서 사람이 채점한 예시를 빼자 최고 등급을 받은 학생이 4명에서 21명으로 늘었으며, 부정 기준을 넣어 다시 보정했다.
- **등급이 일으킨 논쟁:** 세특 분석기는 등급 척도를 썼고 마지막 판은 9등급제였다. 등급을 없애고 원문에 직접 표시한 뒤 개수와 비율을 보여 주도록 바꾸었다.
